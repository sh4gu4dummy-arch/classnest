# Developer-only launchers

`Open-ClassNest-dev.bat` / `Open-ClassNest-dev.command` start the Vite dev
server (`npm run dev:local`) on http://127.0.0.1:3847/. They need Node.js and
`npm install`. Teachers do not use these: they double-click
`Start-ClassNest.bat` at the repo root (http://127.0.0.1:8765/, nothing to
install). See [docs/offline-launcher.md](../../docs/offline-launcher.md).
